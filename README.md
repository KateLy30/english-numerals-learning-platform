## English Numerals Learning Platform

Веб-приложение для изучения правил записи числительных на английском языке.

## О проекте

**English Numerals Learning Platform** — учебный проект, представляющий собой интерактивный тренажёр для практики записи числительных английскими словами.

Пользователь получает числовое значение и должен записать его словами на английском языке, после чего приложение проверяет ответ и помогает разобраться в допущенных ошибках.

## Планируемые возможности

- Тренировка количественных и порядковых числительных
- Работа с датами и годами
- Запись денежных сумм и валют
- Дроби, десятичные числа и проценты
- Телефонные номера
- Поддержка британского и американского вариантов английского
- Несколько уровней сложности

## Технологии

**Backend:** C#, ASP.NET Core Web API, Entity Framework Core

**Frontend:** React, TypeScript, Vite

**Database:** PostgreSQL

**Tools:** Git, GitHub, Docker
